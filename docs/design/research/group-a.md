# Group A: 3D and cinematic references

All eight pages were fetched on 2026-10-27. None states a licence on the component page (each links to a separate Licence page; Aceternity sells an All-Access bundle; Magic UI links to GitHub). None of their source was copied. Every implementation below is original and uses only installed dependencies (`framer-motion`, `three`, `lucide-react`). Files live in `src/components/fx/scene/`; shared helpers (deterministic PRNG, `visibleLoop`, viewport and media hooks) are in `shared.ts`.

Render-on-demand rule used throughout: `visibleLoop` runs `requestAnimationFrame` only while the element intersects the viewport and `document.hidden` is false, and a step may return `false` to go idle until `wake()`.
